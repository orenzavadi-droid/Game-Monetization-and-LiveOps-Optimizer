# Review checklist before using the project professionally

- [ ] Can explain the business tradeoff: conversion vs revenue/user.
- [ ] Can distinguish event-eligible randomized cohort from install cohort.
- [ ] Can define ARPDAU, ARPPU, IAP RPU14 and 14-day payer conversion denominators.
- [ ] Can explain why daily observations must not be treated as independent experimental units.
- [ ] Can describe one difference between the two arms and where it is encoded.
- [ ] Can explain the event price response formula as a chosen assumption, not evidence.
- [ ] Can show how the user-level bootstrap interval is generated.
- [ ] Can explain the pre-specified primary metric and two guardrails.
- [ ] Can show how six SQL queries answer business questions.
- [ ] Can explain how `revenue_reconciliation.sql` ensures data integrity.
- [ ] Can explain why D7 return barely shifts by design in the synthetic model.
- [ ] Can articulate why a wider price-grid optimum cannot be inferred from assumed elasticity.
- [ ] Can describe a real-world follow-up experiment, limitations, and required calibration.
