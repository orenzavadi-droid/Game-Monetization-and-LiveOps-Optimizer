# Synthetic event spec

- Title: Treasure Trail (fictitious, no copyrighted game assets)
- Event: days 1–14 of a 21-day follow-up window
- Randomized cohort: 12,000 event-eligible synthetic players, all first-day active
- Arm A: limited-time special bundle $4.99; Arm B: same bundle $3.99
- Event reward mechanics: 1 or 2 milestone points per participating active day; completion at 8
- Organic IAP: fixed $2.99 purchase chance on active days, both arms
- One special bundle purchase maximum per user during event
- Engagement and churn treatment effects are deliberately zero in this demonstration
- User logins, event participation and purchases derive from explicit stochastic assumptions
- The question is revenue per randomized user, not merely conversion to payers
